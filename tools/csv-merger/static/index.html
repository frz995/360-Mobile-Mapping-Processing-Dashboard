Panorama CSV Toolkit — sort tour metadata, merge it per subgrid, then roll all child metadata into one master file per date.

Scans the folder recursively — nested exports like …\003485-20220904-144310\7\panoramas.csv are copied into the metadata folder renamed to their tour name 003485-20220904-144310.csv. Only panorama CSVs are handled; tracks.csv and logs are skipped, sources never modified.

Groups 003485-20220904-144310.csv-style files by their YYYYMMDD token and merges each group into one file, header once, rows in capture-time order. Files already named YYYYMMDD.csv are treated as previous outputs and skipped, so re-running is safe.

Rolls every child YYYYMMDD.csv produced by Merge Metadata in this folder into one master file named after the subgrid — e.g. N93E70.csv (dates oldest first). Raw tour CSVs and the master file itself are never re-read, so re-running is safe.
